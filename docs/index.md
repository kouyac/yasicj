## 一、 新版雅思成绩单样本整体视觉结构

新版雅思成绩单整体采用模块化设计，排版严谨、字体清晰，主要由以下五个核心区域构成：

### 1. 官方机构标识区（顶部）
*   **左上角**：醒目的黑色 **IELTS™** 官方注册商标标识。
*   **右上角**：英国资格认证和考试管理办公室 **Ofqual REGULATED** 的官方认证标志，彰显成绩单的国际权威性。
*   **表头**：明确标注 **Test Report Form**（成绩报告单）以及考试类别（如：*IELTS Academic*）。

### 2. 考生基础信息区（Candidate Details）
包含考生的核心建档信息，所有信息均有严格的格式规范：
*   **Centre Number（考点代码）** 与 **Candidate Number（考生号）**。
*   **Test Date（考试日期）**。
*   **Candidate Details（考生姓名、证件号/Candidate ID）**。
*   **出生日期（Date of Birth）**、**性别（Sex）**、**国籍与母语（Country of Nationality / First Language）**。
*   **照片**：右侧配有考生现场采集的数字化免冠照片。

### 3. 考试成绩模块（Test Results）
这是成绩单的核心部分，清晰列出四项单科成绩及总分，并完美对接国际标准：
*   **听、说、读、写四科单项分**（Listening, Reading, Writing, Speaking）。
*   **Overall Band Score（总成绩）**。
*   **CEFR Level（欧洲语言共同参考框架等级）**：例如，总分 6.5 分对应 **B2** 等级。

### 4. 官方签证与评语区（底部中段）
*   **Administrator Comments**：官方管理员评语或备注栏。
*   **在线核查提示**：明确标注 *Recognising organisations must verify this score at ielts.org/verify*，提示接收机构必须进行线上核查。
*   **Validation Stamp（官方红章）**：右侧盖有圆形的 **IELTS 官方红色防伪验证签章**。

### 5. 联合主办方版权区（最底部）
*   底部清晰印有 **BRITISH COUNCIL（英国文化教育协会）**、**IDP**、**CAMBRIDGE English（剑桥大学英语考评部）** 三方联合主办的标志及版权声明。

| 识别视觉点 | 官方正品标准样式 |

| **Test Report Form Number** | 右下角独一无二的成绩单编号，包含特定字母与数字组合，是线上核查的唯一钥匙。 |

## 三、 为什么“成绩单制作样式”无法绕过官方核查？

市场上关于“雅思成绩单制作”的传言层出不穷，但需要明确的是，现代雅思成绩的审核早已不是单纯的“看纸张”。**雅思官方拥有全球联动的数字化在线核查系统（TRF Verification Service）。**

1.  **唯一编码验证**：任何纸质成绩单右下角的 `Test Report Form Number` 必须与官方数据库完全匹配。
2.  **机构直接对接**：海外高校、移民局及雇主在收到纸质成绩单后，均会登录官方专有通道（`ielts.org/verify`）输入编号验证真实成绩。
3.  **零容忍政策**：一旦发现纸质样式与系统数据不符，将被判定为欺诈，面临永久禁考及申请一票否决的严重后果。
